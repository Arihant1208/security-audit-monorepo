Setup & Usage Guide

Get from zero to first audit in under 2 minutes. Works with any codebase, any language.

Prerequisites

☑

VS Code

Latest version with GitHub Copilot and Copilot Chat extensions installed.

☑

Copilot Subscription

Individual, Business, or Enterprise. Agent mode must be enabled.

☑

API Key (optional)

Free for remote server access. Not needed for local/stdio mode.

Setup

Step 1 — Install Client Files

Copy agent files into your project. These are lightweight markdown files — zero dependencies, zero build step.

npx degit Arihant1208/security-audit-monorepo/packages/client my-project

This adds the following to your project:

your-project/
├── .vscode/mcp.json           ← MCP connection config
├── .github/
│   ├── agents/
│   │   ├── security-scanner.agent.md
│   │   ├── security-reporter.agent.md
│   │   └── security-fixer.agent.md
│   └── prompts/
│       ├── scan-codebase.prompt.md
│       ├── generate-report.prompt.md
│       ├── fix-vulnerabilities.prompt.md
│       └── full-audit.prompt.md
└── .gitignore

Step 2 — Connect to the MCP Server

Open your project in VS Code. Copilot reads .vscode/mcp.json and prompts you for:

InputValue
Server URLhttps://api.security-audit.dev/mcp
API KeyYour key from the dashboard

VS Code stores the API key securely — it never appears in your project files.

Step 3 — Verify Connection

Open Copilot Chat and type:

@security-scanner List the available security checklists

If the agent responds with 12 checklist layers, you're connected and ready to scan.

Usage

Slash Commands

Type these in GitHub Copilot Chat to run audit workflows:

CommandWhat it does
/full-auditRun all three phases: scan → report → fix
/scan-codebaseScan for vulnerabilities across 12 layers
/generate-reportGenerate audit report + executive summary
/fix-vulnerabilitiesWalk through fixes, highest risk first

Agent Invocation

Use agents directly for targeted queries:

@security-scanner Check for SQL injection in this project
@security-reporter Generate a SOC 2 compliance report
@security-fixer Fix the XSS issue in src/search.ts

Audit Output

All results are written to audit-results/ in your project:

audit-results/
├── scan-results.md        ← Findings with severity & evidence
├── audit-report.md        ← Full technical audit report
├── executive-summary.md   ← Leadership summary (non-technical)
├── remediation-log.md     ← Log of applied fixes
└── findings/
    ├── V-001.md           ← Individual Critical/High reports
    └── ...

Risk Scoring

Each finding gets a risk score from 0–10 using: Risk = min(10, Impact × Exploitability × Exposure + Business Context)

ScoreLevelRemediation SLA
9.0 – 10.0CriticalFix within 24–48 hours
7.0 – 8.9HighFix within 1–2 weeks
4.0 – 6.9MediumFix within 1–3 months
2.0 – 3.9LowNext development cycle
0 – 1.9InformationalAddress opportunistically

Self-Hosting Options

A

stdio (Local, No Network)

Run the MCP server as a VS Code subprocess. No API key needed. Fully air-gapped.

B

Docker (Local HTTP)

Run with Docker Compose. Includes PostgreSQL for key management & analytics.

C

Cloud (Free Tier)

Deploy to Render, Fly.io, Railway, or HF Spaces. Setup in under 5 minutes.

Option A — stdio (zero network)

git clone https://github.com/Arihant1208/security-audit-monorepo.git && cd security-audit-monorepo && npm install && npm run build

Then update .vscode/mcp.json in your project:

{
  "servers": {
    "security-audit": {
      "type": "stdio",
      "command": "node",
      "args": ["/path/to/security-audit/packages/mcp-server/dist/index.js", "--stdio"],
      "env": {
        "SECURITY_AUDIT_SKIP_AUTH": "true"
      }
    }
  }
}

Option B — Docker Compose

git clone https://github.com/Arihant1208/security-audit-monorepo.git && cd security-audit-monorepo
docker compose -f infra/docker-compose.yml up -d

Server runs at http://localhost:3000/mcp — test key: sa_test_localdev1234567890abcdef

Troubleshooting

MCP server not responding

Check the MCP indicator in the VS Code status bar. Verify your API key. For local: curl http://localhost:3000/health

No tools available

Restart VS Code to re-initialize the MCP connection. Check .vscode/mcp.json syntax. Ensure the server URL is reachable.

Agents don't appear

Agent files must be in .github/agents/. Restart VS Code after adding them. Check YAML frontmatter is valid.

Scan produces no findings

Verify MCP connection by listing checklists. Small projects may have fewer findings. Check audit-results/ for partial output.
