# Audit Checklists

Actionable checklists for each layer of the security audit. Use these during [Phase 4: Layered Security Audit](../methodology/04-layered-security-audit.md).

## Usage

For each checklist item:
- **PASS** — Control is properly implemented
- **FAIL** — Control is missing or insufficient (document as finding)
- **N/A** — Not applicable to this system
- **PARTIAL** — Partially implemented (document gaps)
